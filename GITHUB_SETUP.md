# GitHub setup from an Android phone

1. Open https://github.com in Chrome and sign in.
2. Tap the `+` menu, then choose **New repository**.
3. Repository name: `cricket-universe-27`
4. Description: `Original 3D cricket game prototype built with Unity`
5. Choose **Private** while the project is early-stage.
6. Select **Add a README file** and create the repository.
7. Open the new repository, choose **Add file → Upload files**.
8. Upload the contents of this starter folder, preserving the `Assets/Scripts/` folder structure and `.gitignore`.
9. Commit the upload to the `main` branch.
10. Copy the repository URL and share it in the project chat.

Important: This starter kit contains scripts and setup documentation, not a complete Unity project. A Unity Editor session must first create a 3D project and generate `ProjectSettings/`, `Packages/`, and `ProjectSettings/ProjectVersion.txt`. Add those generated project files to the repository before configuring Unity Build Automation.

Do not upload passwords, access tokens, signing keys, keystores, or private credentials. Do not make the repository public unless you deliberately want the source code publicly visible.
